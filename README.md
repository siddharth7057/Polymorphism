# 🚀 Java Method Overloading – Practice Programs

This repository contains a collection of **Java programs demonstrating Method Overloading**, written as part of practice and learning exercises. Each problem focuses on using the same method name with different parameter lists to perform related operations.

---

## 📌 Topics Covered

* Method Overloading in Java
* Data types and return types
* Mathematical and utility-based problems
* Clean, beginner-friendly Java logic

---

## 📂 Programs Included

### 🔢 1. AreaCalculator

Calculates areas of different shapes using overloaded methods.

**Overloaded Methods:**

* `calculateArea(double side)` → Area of a **square**
* `calculateArea(double length, double breadth)` → Area of a **rectangle**
* `calculateArea(float radius)` → Area of a **circle**

**Concept Used:** Same method name with different parameter lists.

---

### 🔁 2. Converter

Performs multiple conversion operations using method overloading.

**Overloaded Methods:**

* `convert(double km)` → Kilometers to **miles**
* `convert(int celsius)` → Celsius to **Fahrenheit**
* `convert(char ch)` → Character to **ASCII value**

**Concept Used:** Method overloading with different data types.

---

### ⚡ 3. PowerCalculator

Calculates power of numbers using overloaded methods.

**Overloaded Methods:**

* `power(int base, int exponent)` → Integer power calculation
* `power(double base, int exponent)` → Floating-point base power
* `power(int base)` → Square of a number (base²)

**Concept Used:** Method overloading with varying parameter counts.

---

### 📈 4. MaximumFinder

Finds the maximum value among given numbers.

**Overloaded Methods:**

* `findMax(int a, int b)` → Maximum of two integers
* `findMax(int a, int b, int c)` → Maximum of three integers
* `findMax(float a, float b)` → Maximum of two floats

**Concept Used:** Method overloading for different argument combinations.

---

### 💰 5. BillGenerator

Generates bills with optional tax and discount.

**Overloaded Methods:**

* `generateBill(double price)` → Base price only
* `generateBill(double price, double tax)` → Base price + tax
* `generateBill(double price, double tax, double discount)` → Base price + tax − discount

**Concept Used:** Method overloading for flexible billing logic.
